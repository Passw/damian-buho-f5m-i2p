# Configuration

## Configuration del proyecto

### Variables de entorno

Cambia cualquiera con `--env NOMBRE=valor`; el valor por omisión es el que trae la imagen.

| Variable | Por omisión |
| --- | --- |
| `B19_JAVA_XMS` | `128m` |
| `B19_JAVA_XMX` | `256m` |
| `F5M_I2P_BROWSER_LAUNCH_ENABLED` | `false` |
| `F5M_I2P_CONSOLE_PORT` | `7657` |
| `F5M_I2P_EEPSITE_ENABLED` | `true` |
| `F5M_I2P_EEPSITE_INBOUND_LENGTH` | `3` |
| `F5M_I2P_EEPSITE_INBOUND_QUANTITY` | `2` |
| `B19_HEALTH_EGRESS` | `true` |
