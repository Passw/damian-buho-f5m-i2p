# Конфігурація I2P, відтворена з Jinja2

- Маршрутизатор, тунелі, клієнти, wrapper і параметри JVM — усе відтворюється з шаблонів Jinja2 під час запуску.
- Відтворена конфігурація записується в каталог маршрутизатора під час кожного запуску, тож достатньо змінити змінну середовища й перестворити контейнер — очищати том не потрібно.
- Кожну підсистему I2P (SAM, IRC, POP3, SMTP, Jetty, SSH, запуск браузера) можна вмикати й вимикати змінними середовища.
- Довжину та кількість вхідних і вихідних тунелів можна налаштувати для кожного тунеля eepsite.
